# Зубрик: Telegram-бот и Mini App для учеников курса

Учитель (Telegram ID `7183098167`, задаётся в `ADMIN_IDS`) создаёт группы, добавляет туда учеников и отправляет им тесты. Ученики решают тесты в Mini App в стиле Duolingo и смотрят статистику на диаграммах.

## Главная задача Claude в этом репо: конспект → тест

Когда учитель присылает конспект урока:

1. Сделай файл `content/lessons/<id>.json`. `id` пишется латиницей через дефис, например `lesson-03-fractions`.
2. Делай 8–15 вопросов **строго по конспекту**, смешивая типы. Сложность нарастает от простого к сложному. Каждому вопросу ставь `topic`: короткую подтему урока (3–6 разных тем на урок). Из них строится радар-диаграмма. В `explain` коротко объясни, почему ответ такой.
3. Проверь: `npm run check`.
4. Сделай commit и push в рабочую ветку. Render сам передеплоит, и тест появится у учителя во вкладке «Тесты» как **черновик**. Ученики его не видят, пока учитель не нажмёт «Отправить» и не выберет группу.

Если урок уже решали ученики, вопросы при импорте из `content/` не перезаписываются. Чтобы поменять такой урок, сделай новый `id`.

### Формат урока

```json
{
  "id": "lesson-03-fractions",
  "title": "Дроби: сложение",
  "emoji": "🧮",
  "description": "Одна строка о чём урок",
  "questions": [
    { "type": "choice", "topic": "Тема", "prompt": "Вопрос?", "options": ["A", "B", "C", "D"], "answer": 1, "explain": "…" },
    { "type": "truefalse", "topic": "Тема", "prompt": "Утверждение", "answer": true },
    { "type": "input", "topic": "Тема", "prompt": "Вопрос с коротким ответом", "answer": ["основной вариант", "допустимый вариант"] },
    { "type": "order", "topic": "Тема", "prompt": "Собери …", "tokens": ["в", "правильном", "порядке"], "extra": ["лишнее"] },
    { "type": "match", "topic": "Тема", "prompt": "Соедини пары", "pairs": [["термин", "определение"], ["…", "…"]] }
  ]
}
```

Необязательные поля вопроса: `hint` (подсказка), `code` (блок кода под вопросом). Ответы `input` сравниваются без учёта регистра, ё/е и точки в конце.

## Устройство

- `src/server.js`: Express API и бот (webhook, если есть публичный https-URL, иначе long polling). Напоминания проверяются каждые 30 секунд.
- `src/logic.js`: вся предметная логика: группы, публикации, попытки, XP, комбо, серии, статистика.
  - «Работа над ошибками»: у каждого ученика копилка вопросов, на которые его последний ответ был неверным (`mistakesOf`). Из неё собирается личный тест до 10 вопросов (`POST /api/attempts {mistakes:true}`). Если ученик отвечает верно, вопрос уходит из копилки.
- `src/bot.js`: команды `/start`, `/link` (привязать чат Telegram-группы к группе курса), `/stop`, уведомления о тестах, напоминания.
- `src/store.js`: всё состояние в одном JSON-документе. В продакшене он лежит в Postgres (`DATABASE_URL`), локально в `data/state.json`.
- `public/`: Mini App без сборки (vanilla JS), графики на SVG.
  - `mascots.js`: 5 маскотов-напарников (mimi, kapi, dino, axi, boo) × 9 эмоций (happy, cheer, oops, sad, think, wow, love, sleepy, peace), рисуются SVG-кодом.
  - `icons.js`: иконки интерфейса Solar (bold-duotone). Новые иконки берутся из `@iconify-json/solar`.
  - `e/`: 3D-эмодзи Fluent (`<код>.webp` + `index.json`), `ea/`: анимированные. Любой эмодзи в `emoji` урока или группы автоматически рисуется в 3D.
  - Ученик сам выбирает напарника, цвет (lime, sakura, lavender, ocean, peach, mint) и тему (auto, light, dark), всё это хранится в `user.prefs`.

Локальный запуск без Telegram: `npm run dev`, потом открыть `http://localhost:3000/?dev=7183098167` (учитель) или `?dev=111&name=Ученик`.

Переменные окружения: `BOT_TOKEN`, `DATABASE_URL`, `ADMIN_IDS`, `PUBLIC_URL` (на Render берётся `RENDER_EXTERNAL_URL`), `ADMIN_TOKEN` (опционально, Bearer-доступ к `/api/admin/*`), `APP_LINK` (ссылка для кнопки в группах, по умолчанию `https://t.me/<bot>?start=play`).
