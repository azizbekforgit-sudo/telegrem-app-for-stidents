# Мир Зубрика в Roblox — инструкция для учителя (за 15 минут)

11 уровней Урока 8: ученица пишет CSS Grid в приложении «Зубрик», нажимает **«Отправить в мир»**, и принтер в игре печатает фигуры из этого кода. Она берёт предмет (**[E]**), несёт его к сияющей рамке (рядом он сам «примеряется» на место), кладёт (**[E]**) и идёт к флагу. Если в CSS ошибка, предмет разваливается, а питомец объясняет, что поправить. Все тексты игры — на языке ученика (ru, uz, en).

## 1. Установка Rojo
1. Скачайте **Rojo** (CLI + плагин для Roblox Studio) с [rojo.space](https://rojo.space/).
2. Установите плагин Rojo в Roblox Studio.

## 2. Настройка адреса сервера
Откройте файл `roblox/src/shared/Config.lua` и впишите адрес вашего сервера (без `/` в конце):
- Для локального теста: `Config.SERVER_URL = "http://localhost:3000"`
- Для продакшена (Render): `Config.SERVER_URL = "https://ваш-сервис.onrender.com"`

*Для теста в Studio со своим локальным сервером задайте у `Workspace` атрибут `ZubrikServer` (`http://localhost:3000`): код сначала проверится там, а если не подошёл — на `SERVER_URL`. В опубликованной игре атрибут не действует. Звуки — в `Config.SOUNDS` (бесплатные из Creator Store).*

## 3. Запуск и синхронизация со Studio
1. В корне репозитория выполните:
   ```bash
   rojo serve
   ```
2. Откройте **Roblox Studio** → создайте пустой **Baseplate** (или выберите существующий).
3. В Roblox Studio откройте плагин **Rojo** и нажмите **Connect**.
4. Включите HTTP-запросы: **Game Settings → Security → Allow HTTP Requests → On** → Save.

## 4. Публикация и безопасность для класса
1. **Отключите чат** (для безопасности детей в классе):
   - В `Explorer` → `TextChatService` → `ChatWindowConfiguration` и `ChatInputBarConfiguration` снимите `Enabled`.
2. **Опубликуйте игру как приватную** (**File → Publish to Roblox As…**, выберите **Private** или **Friends/Group** только для вашего класса).
3. **Возраст 13-:** ученикам младше 13 лет в Roblox нужен аккаунт с подтверждённым согласием родителей (Parental Consent), чтобы играть в пользовательские миры и видеть фильтрованный контент.
4. Отправьте ученикам ссылку на игру. В одном сервере автоматически создаётся до **8 изолированных островов** — весь класс может играть одновременно, не мешая друг другу.

## 5. Как проходит урок
1. Ученица заходит в Roblox → вводит **6-значный код** из приложения «Зубрик» (`Задачи → Мир Roblox → Получить код`) или от бота (`/world`). Рядом появляется её питомец.
2. Открывает редактор в приложении, пишет CSS Grid и жмёт **«Отправить в мир»**.
3. Принтер печатает фигуры. **[E]** взять → отнести к сияющей рамке → **[E]** положить (на телефоне — кнопки на экране).
4. Доходит до флага: **+80…240 XP**, уведомление в боте «Ура, уровень пройден, открыт следующий», открываются ворота к следующему острову. Кнопка 🗺 — переход по открытым уровням.
