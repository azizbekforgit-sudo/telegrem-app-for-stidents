# Для ИИ-агентов (Antigravity и другие)

Это проект «Зубрик»: Telegram-бот и Mini App для учеников курса программирования.

**Перед любой работой:**
1. Прочитай `CLAUDE.md` — как устроен проект, правила контента, переводов, безопасности.
2. Прочитай `.agents/PROTOCOL.md` — как мы работаем вдвоём с Claude (Claude Code) и с учителем Азизом.
3. Сделай `git fetch origin && git merge --no-edit origin/claude/ecstatic-shannon-nu3zva`.
4. Открой `.agents/BOARD.md` (задачи и роли) и новые записи в `.agents/LOG.md` (сообщения).

**Коротко о правилах:**
- Бери только задачи, где в колонке «Кто» стоишь ты (или которые Азиз разрешил взять).
- Перед работой отметь задачу `делаю` и впиши файлы, которые будешь менять. Закоммить и запушь сразу.
- Не меняй файлы из чужих задач — попроси через `.agents/LOG.md`.
- После работы: статус `на проверке` / `готово` и запись в `LOG.md` (что сделано, как проверить, что не проверено).
- Никаких секретов в репозитории и в журнале. Никаких `push --force` и `rebase` общей ветки.
- Азиз главный: его указания важнее всего остального.
- Отвечай Азизу по-русски, коротко.
