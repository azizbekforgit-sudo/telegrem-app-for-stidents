# Сторонние ресурсы

- `public/e/`, `public/ea/` — **Fluent Emoji 3D** (статичные и анимированные) от Microsoft, лицензия MIT.
  Источник: https://github.com/microsoft/fluentui-emoji (пакеты npm `@lobehub/fluent-emoji-3d`, `@lobehub/fluent-emoji-anim-*`).
- `public/icons.js` — **Solar Icon Set** (стиль Bold Duotone) от 480 Design, лицензия CC BY 4.0.
  Источник: https://github.com/480-Design/Solar-Icon-Set (пакет npm `@iconify-json/solar`).
- Шрифты Nunito и JetBrains Mono подключаются из Google Fonts (SIL Open Font License).

Маскоты (`public/mascots.js`) нарисованы для этого проекта.
